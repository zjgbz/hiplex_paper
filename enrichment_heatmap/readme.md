# Hiplex Paper - Enrichment Heatmap

## Overview
This command is used to generate enrichment heatmaps from genomic data. Please follow the instructions below to ensure the correct setup and usage of the scripts.

## Prerequisites
Before running the analysis, ensure you have the following R packages installed:

- **GenomicAlignments**
- **Biostrings**
- **EnrichedHeatmap**
- **rtracklayer**
- **data.table**
- **circlize**
- **glue**

Note: The script will automatically install missing packages when run.

## Directory Structure
Make sure you are in the `hiplex_paper`directory:

`cd /path/to/your/hiplex_paper`

## How to Run
Run in terminal:

`bash enrichment_heatmap/run_enrich_heatmap.sh` (approximately 30 minutes)

## Output/Results

The expected output directory is: 

`../results/Figure1/`

Within this directory, you will find PDF files generated by the analysis with names formatted as: `{target1_name}_{target2_name}.pdf`
